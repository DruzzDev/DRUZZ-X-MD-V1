## `<img src="https://cdn.simpleicons.org/whatsapp/25D366" width="22"/>`{=html} About DRUZZ X-MD

**DRUZZ X-MD** is a professional, customizable and open-source WhatsApp
bot built with **Node.js** and **Baileys**.

The project is designed for developers and bot builders who want a
strong starting point for creating their own WhatsApp automation system.

> [**DRUZZ X-MD is FREE SOURCE CODE.**]{style="color:#8B5CF6"}

### [Main Goals]{style="color:#00E5FF"}

-   ⚡ Fast and responsive WhatsApp automation
-   🧩 Modular command system
-   🛠️ Easy customization
-   🌐 Deployable on multiple platforms
-   📦 Easy ZIP download and installation
-   🔓 Free source code for developers
-   🚀 Designed to grow with new commands and features

# [📥 Download DRUZZ X-MD]{style="color:#00E5FF"}

## Method 1 --- Download ZIP from GitHub

1.  Open the **DRUZZ X-MD GitHub repository**.
2.  Press the green **Code** button.
3.  Select **Download ZIP**.
4.  Extract the ZIP file on your computer or Android device.
5.  Open the extracted project folder.
6.  Install the dependencies.
7.  Configure your environment variables.
8.  Start the bot.

### Install dependencies

``` bash
npm install
```

### Start the bot

``` bash
npm start
```

### Development mode

``` bash
npm run dev
```

# [🚂 Deploy on Railway]{style="color:#8B5CF6"}

::: {align="center"}
`<img src="https://cdn.simpleicons.org/railway/8B5CF6" width="55" alt="Railway"/>`{=html}
:::

### Steps

1.  Create or open your GitHub repository.
2.  Push the **DRUZZ X-MD** source code.
3.  Open Railway.
4.  Create a new project.
5.  Select **Deploy from GitHub Repo**.
6.  Choose your DRUZZ X-MD repository.
7.  Railway installs the dependencies.
8.  Add your required environment variables in **Variables**.
9.  Deploy the project.
10. Check the deployment logs for errors.

### Recommended commands

**Build / Install:**

``` bash
npm install
```

**Start:**

``` bash
npm start
```

If your project has a `start` script in `package.json`, Railway can use:

``` bash
npm start
```

# [🟢 Deploy on Render]{style="color:#00FF88"}

::: {align="center"}
`<img src="https://cdn.simpleicons.org/render/46E3B7" width="55" alt="Render"/>`{=html}
:::

### Steps

1.  Push the project to GitHub.
2.  Open Render.
3.  Create a new service.
4.  Connect your GitHub repository.
5.  Select the DRUZZ X-MD repository.
6.  Choose the appropriate service type for your bot.
7.  Set the build command:

``` bash
npm install
```

8.  Set the start command:

``` bash
npm start
```

9.  Add environment variables.
10. Deploy and inspect the logs.

> **Important:** A WhatsApp bot normally needs a continuously running
> process. Choose a Render service type suitable for a long-running
> Node.js process rather than treating the bot like a static website.

# 🌐 DRUZZ X-MD Web Pairing

The bot no longer requires Telegram for WhatsApp pairing. Open the deployed website, enter the WhatsApp number with country code, and generate the pairing code directly in the browser.

The web interface is served by the same Node.js/Express server and uses Socket.IO for live pairing and connection status.

```bash
npm install
npm start
```

Then open the deployed URL.

> **Security:** keep WhatsApp auth/session files and environment secrets private. Do not commit `auth_info/`, `.env`, or credentials to a public repository.
